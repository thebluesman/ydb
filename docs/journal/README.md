# Project Journal

Chronological record of decisions, scope changes, and process changes for YDB. Owned by `@historian`.

## How to read this journal

Each month is its own file (`YYYY-MM.md`), with entries grouped by date. The journal points to
canonical artifacts — ADRs, PRD sections, agent definitions — and never duplicates their content. To
understand a decision in detail, follow the link.

Categories:

| Tag | Use for |
|---|---|
| `[decision]` | Load-bearing choice — architecture, tooling, scope-defining commitment. |
| `[scope]` | What is or isn't in a project or phase. Includes deferrals with triggers. |
| `[process]` | How the team works — conventions, agent rules. |
| `[refactor]` | Non-functional reorganization worth remembering. |
| `[ops]` | Tooling, MCP, hooks, repo structure, build/test setup. |
