- **[scope]** `[chat-sql] 9` filed from architecture discovery: `TABLE_SOURCE_RE`'s alias-slot capture group over-consumes and swallows the following `JOIN`/`FROM` keyword, causing `Account` to be unrecognized as a table qualifier on unaliased joins. Comma joins fail by a separate mechanism (`,` isn't a source-introducing token). No ADR: this is a parsing defect in code that implements ADR-0018, not a design-decision change; `docs/architecture.md`'s Open Questions section absorbed the correction instead. Ticket owner: `@backend-engineer`. → Commit `647ee07`, Notion ticket [`[chat-sql] 9`](https://app.notion.com/p/3afa225a2512816fbd4fff31004e7052).
